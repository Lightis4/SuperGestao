🛒 SuperGestão — Sistema de Gerenciamento de Supermercado

O SuperGestão é um sistema de gerenciamento de supermercado desenvolvido em **Python**, com interface gráfica utilizando **Tkinter** e banco de dados PostgreSQL, hospedado na plataforma Neon.

O projeto foi desenvolvido com finalidade acadêmica, aplicando conceitos de programação orientada a objetos, operações CRUD, banco de dados relacional e organização modular de software.

🎯 Objetivo

Desenvolver uma aplicação desktop que facilite o gerenciamento de produtos, fornecedores, estoque e movimentações comerciais de um supermercado.

🚀 Funcionalidades

- Cadastro, edição, exclusão e consulta de produtos.
- Cadastro, edição, exclusão e consulta de fornecedores.
- Controle de estoque.
- Registro de compras e vendas.
- Atualização automática das quantidades em estoque.
- Histórico de movimentações.
- Armazenamento de informações em banco de dados online.

🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
| Python | Linguagem principal |
| Tkinter | Interface gráfica desktop |
| PostgreSQL | Banco de dados relacional |
| Neon | Hospedagem do PostgreSQL |
| Psycopg | Comunicação entre Python e PostgreSQL |
| Python-dotenv | Gerenciamento de variáveis de ambiente |
| Git e GitHub | Versionamento e armazenamento do código |
